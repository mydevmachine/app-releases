# Devmachine for Mac — releases

Signed and notarized builds of Devmachine, the macOS desktop app for
[devmachine](https://mydevmachine.sh). Download the latest `.dmg` from
[Releases](https://github.com/mydevmachine/app-releases/releases).

Devmachine needs the devmachine CLI and a machine set up with it:

```
brew install mydevmachine/tap/devmachine
devmachine setup
```

macOS 14 or later. More at https://mydevmachine.sh/app/.
